# Threat Modeling and Secure Configuration

## Project Overview
This project focuses on identifying potential security threats in a small web application using the STRIDE threat modelling methodology.

## Project Objectives
- Identify potential security threats.
- Understand application architecture and trust boundaries.
- Perform STRIDE threat analysis.
- Assess and prioritize security risks.
- Prepare a security hardening plan.

## Application Features
- User Registration
- User Login
- User Profile Management
- Password Reset

## Architecture Components
1. User Browser
2. Web Application
3. Authentication Module
4. User Database
5. Email Service

## Security Assessment
- Reviewed OWASP ZAP vulnerability scan results.
- Identified potential security issues.
- Reviewed security headers and cookie configuration.
- Prepared STRIDE threat analysis.
- Performed preliminary risk assessment.

## STRIDE Analysis
- Spoofing
- Tampering
- Repudiation
- Information Disclosure
- Denial of Service
- Elevation of Privilege

## Risk Assessment
Risks are prioritized based on likelihood and impact.

## Security Hardening Plan
- Strong authentication
- Secure password hashing
- Server-side authorization
- SQL injection prevention recommendations
- Secure session management
- HTTPS configuration
- Security logging

## Tools Used
- OWASP ZAP
- Kali Linux
